# Retail Sales Analysis

## Project Overview

This project analyzes a retail sales dataset using Python and Jupyter Notebook to identify sales trends, customer behavior, and product performance.

## Objectives

- Analyze overall retail sales performance
- Identify revenue by product category
- Study customer distribution by age group
- Analyze spending patterns across age groups
- Examine relationships between quantity, price, and total amount
- Compare revenue across gender and product categories

## Dataset

The dataset contains 1,000 retail transactions with information such as:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Data loading and exploration
- Missing-value checking
- Statistical analysis
- Correlation analysis
- Revenue analysis by product category
- Monthly revenue trend analysis
- Customer age-group analysis
- Average spending analysis
- Gender and category revenue analysis
- Quantity vs. total amount analysis
- Price per unit vs. total amount analysis

## Key Findings

- Clothing generated the highest number of transactions.
- Electronics had the highest revenue share, followed closely by Clothing.
- The 46–55 age group had the highest number of customers.
- Younger customers showed higher average spending than older age groups.
- Price per Unit had a strong positive relationship with Total Amount.
- Revenue varied significantly across different months.

## Project Files

- `retail_sales_analysis.ipynb` — Jupyter Notebook containing the complete analysis
- `retail_sales_dataset.csv` — Dataset used for analysis

## Conclusion

The analysis provides insights into customer behavior, product performance, revenue trends, and purchasing patterns. These insights can help businesses better understand their customers and make data-driven decisions.
